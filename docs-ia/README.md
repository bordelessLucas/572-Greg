# Documentação IA do projeto Greg

Este diretório centraliza o contexto que deve orientar as próximas etapas do projeto. Leia estes arquivos antes de implementar novas telas, fluxos, regras de negócio, dados, integrações, ou automações.

## Ordem de leitura

1. [`context.md`](context.md): contexto do cliente, operação atual, problema central, e limites do projeto.
2. [`escopo.md`](escopo.md): requisitos confirmados, sugestões relacionadas, integrações futuras, e pontos a confirmar.
3. [`design_system.md`](design_system.md): direção visual, tokens, componentes, responsividade, e regras de revisão visual.
4. [`arquitetura.md`](arquitetura.md): arquitetura recomendada para frontend, domínio, dados, serviços, e integrações.
5. [`modelo_dados.md`](modelo_dados.md): entidades iniciais, relações, e campos a confirmar.
6. [`fluxos.md`](fluxos.md): fluxos principais de compra, venda, financeiro, documento, assinatura, cobrança, e IA.
7. [`roadmap.md`](roadmap.md): fases de implementação, MVP, e evoluções futuras.
8. [`modulos/`](modulos): documentação por módulo funcional.

## Princípio central

Informação digitada uma vez deve ser reutilizada em todo o sistema.

O sistema deve reduzir retrabalho, erros, dados incompletos, tarefas repetitivas, e tempo gasto na operação.
