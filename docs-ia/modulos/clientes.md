# Clientes

## Objetivo

Centralizar dados usados em vendas, documentos, pagamentos, cobranças, e histórico.

## Escopo confirmado

O cadastro de clientes deve fornecer dados para:

- Registrar vendas.
- Gerar recibos e contratos.
- Realizar cobranças.
- Acompanhar pagamentos.
- Enviar documentos.

## Pontos a confirmar

- Documento obrigatório.
- Telefone obrigatório.
- E-mail obrigatório.
- Endereço obrigatório.
- Dados mínimos para contrato.
- Dados mínimos para cobrança.
