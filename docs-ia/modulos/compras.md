# Compras

## Objetivo

Registrar compras de produtos e refletir a operação no produto, no fornecedor, e no financeiro.

## Escopo confirmado

- Registrar fornecedor.
- Registrar produto.
- Registrar especificações do produto.
- Registrar valor da compra.
- Registrar forma de pagamento.
- Registrar conta usada no pagamento.
- Guardar informações da operação.

## Sugestões

- Data da compra.
- Observações.
- Comprovantes.
- Quantidade.
- Custo unitário.
- Custo total.

## Automações

- Criar movimentação financeira de saída.
- Atualizar histórico do produto.
- Associar fornecedor à compra.

## Pontos a confirmar

- Se compras podem ter vários produtos.
- Se compras podem ter parcelamento.
- Se comprovantes são obrigatórios.
- Se estoque será atualizado automaticamente.
