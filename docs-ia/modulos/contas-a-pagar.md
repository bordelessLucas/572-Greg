# Contas a pagar

## Objetivo

Controlar obrigações financeiras da empresa.

## Origem dos registros

Contas a pagar podem nascer de:

- Compras parceladas.
- Despesas.
- Compromissos financeiros manuais.

## Sugestões

- Vencimento.
- Categoria.
- Conta de pagamento.
- Status.
- Comprovante.
- Observações.

## Pontos a confirmar

- Se compras geram contas a pagar.
- Se despesas podem ser recorrentes.
- Se o sistema deve avisar vencimentos próximos.
