# Contas a receber

## Objetivo

Controlar vendas não pagas integralmente no ato.

## Escopo confirmado

- Cliente.
- Venda.
- Valor.
- Vencimento.
- Parcelas.
- Situação.
- Valores recebidos.
- Valores pendentes.

## Automações

- Criar contas a receber a partir da venda.
- Atualizar situação ao receber parcela.
- Atualizar fluxo de caixa.
- Destacar parcelas atrasadas.

## Pontos a confirmar

- Regras de atraso.
- Tolerância de vencimento.
- Status usados pelo cliente.
- Se recebimento parcial é permitido.
