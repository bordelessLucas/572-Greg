# Dashboard

## Objetivo

Mostrar a situação diária da operação sem reproduzir uma planilha.

## Informações possíveis

- Vendas do período.
- Compras.
- Entradas.
- Saídas.
- Saldo.
- Contas a receber.
- Parcelas atrasadas.
- Despesas.
- Produtos.
- Clientes.
- Documentos aguardando assinatura.

## Sugestões de UX

- Usar métricas compactas.
- Mostrar pendências prioritárias.
- Exibir atividade recente.
- Dar acesso rápido a nova venda, nova compra, e novo cliente.
- Evitar gráficos decorativos.

## Pontos a confirmar

- Quais indicadores são indispensáveis no primeiro acesso.
- Quais períodos o cliente usa para análise.
- Quais pendências exigem atenção diária.
