# Produtos

## Objetivo

Manter um cadastro reutilizável para compras, vendas, documentos, e histórico.

## Escopo confirmado

- Nome.
- Descrição.
- Especificações.
- Informações usadas na compra.
- Informações usadas na venda.
- Histórico das operações relacionadas.

## Sugestões

- Estoque.
- Quantidade disponível.
- Custo médio.
- Histórico de preço.
- Número de série.
- Código interno.

## Pontos a confirmar

- Se cada unidade precisa de número de série.
- Se o cliente trabalha com produtos usados, novos, ou ambos.
- Se o estoque deve bloquear venda sem disponibilidade.
- Se acessórios entram como produtos.
