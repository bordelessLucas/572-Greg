# Vendas

## Objetivo

Registrar vendas e gerar automaticamente os registros relacionados.

## Escopo confirmado

- Cliente.
- Produto.
- Valor da venda.
- Forma de pagamento.
- Informações de recebimento.

## Derivações esperadas

Uma venda deve reaproveitar:

- Dados do cliente.
- Dados do produto.
- Dados financeiros.
- Dados necessários ao contrato ou recibo.

## Automações

- Registrar financeiro.
- Gerar conta a receber.
- Gerar parcelas.
- Preparar documento.
- Gerar PDF.
- Preparar assinatura.

## Pontos a confirmar

- Se uma venda pode ter vários produtos.
- Se desconto deve existir.
- Se há comissão.
- Se há status de venda.
- Se uma venda pode ser cancelada.
