# Roadmap inicial

## Etapa 1: Base operacional

Objetivo: criar a estrutura mínima para o sistema funcionar como produto.

Entregas:

- Autenticação.
- Dashboard.
- Clientes.
- Fornecedores.
- Produtos.
- Contas financeiras.
- Tokens e componentes visuais.

## Etapa 2: Compras

Objetivo: substituir o controle manual de compras em Excel.

Entregas:

- Cadastro de compra.
- Vínculo com fornecedor.
- Vínculo com produto.
- Forma de pagamento.
- Conta financeira de origem.
- Movimentação financeira de saída.

## Etapa 3: Vendas

Objetivo: registrar vendas e criar registros derivados sem retrabalho.

Entregas:

- Cadastro de venda.
- Vínculo com cliente.
- Vínculo com produto.
- Forma de pagamento.
- Parcelamento.
- Conta a receber.

## Etapa 4: Financeiro

Objetivo: substituir planilhas financeiras.

Entregas:

- Despesas.
- Contas a pagar.
- Contas a receber.
- Fluxo de caixa.
- Categorias.
- Visualizações por período.

## Etapa 5: Documentos

Objetivo: eliminar edição manual no Canva.

Entregas:

- Templates.
- Variáveis.
- Preenchimento automático.
- Pré-visualização.
- Geração de PDF.
- Organização dos documentos.

## Etapa 6: Assinaturas e cobranças

Objetivo: reduzir acompanhamento manual pós-venda.

Entregas:

- Integração com Autentique, se validada.
- Status de assinatura.
- Painel de cobranças.
- Lembretes.
- Mensagens preparadas.

## Etapa 7: Automações e IA

Objetivo: reduzir digitação manual.

Entregas:

- Lançamento por texto.
- Lançamento por voz, se validado.
- Interpretação de compra e venda.
- Tela de revisão antes da gravação.

## Etapa 8: Integração bancária

Objetivo: reduzir conciliação manual.

Entregas:

- Análise do banco usado.
- Avaliação de Open Finance ou API.
- Importação de OFX ou CSV.
- Categorização.
- Vínculo com vendas, parcelas, compras, e despesas.

## Critérios para priorização

Priorize o que:

- Remove uma planilha.
- Remove uma etapa manual.
- Evita dados incompletos.
- Evita digitar o mesmo dado duas vezes.
- Ajuda a cobrar valores em aberto.
- Gera documento sem Canva.

## MVP

O MVP útil deve permitir:

- Cadastrar clientes, fornecedores, produtos, e contas financeiras.
- Registrar compras.
- Registrar vendas.
- Controlar parcelas.
- Ver contas a receber.
- Ver fluxo de caixa.
- Gerar documento e PDF.
- Ver cobranças pendentes.

Autentique pode entrar no MVP se a API estiver disponível e se o cliente priorizar assinatura automática.
